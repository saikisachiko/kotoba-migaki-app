# 言葉磨きアプリ

言葉の表現力を広げるためのWebアプリです。

## 今回のプロトタイプ

スマートフォンを中心にした、利用者向けの3画面のWebアプリです。

1. 今日の問題を読み、自分の言葉を入力します（思いつかない場合はギブアップできます）。
2. 自分の表現と固定のAIコメントを見て、5つの言い換え候補から選びます。「持ち帰る」は追加候補を開いたときだけ表示されます。
3. 「今日の一言にする」または「今日は選ばない」で完了します。

AI API、ログイン、データベース、本物のことば帳は未実装です。「ことば帳に追加しました」は仮表示で、再読み込みすると入力・選択は消えます。サーバーにも保存しません。

## いちばん簡単な確認方法（インストール不要）

このリポジトリのファイルをダウンロードして展開し、`index.html` をダブルクリックしてブラウザで開いてください。`app.js` と `style.css` は、`index.html` と同じフォルダーに置いたままにしてください。インターネットやAPIキーは不要です。

GitHubへ反映された後は、リポジトリ画面の緑色の「Code」→「Download ZIP」で取得できます。

まず好きな短い表現を入力して「この言葉にする」を押し、候補を選び、「今日の一言にする」を押してください。「もう一度試す」からギブアップや「今日は選ばない」も確認できます。

## 開発用の起動方法

Node.js 22以上を使用します。ターミナルで、このリポジトリのフォルダーに移動して次を実行します。

```sh
npm start
```

起動中のパソコンのブラウザで `http://localhost:3000` を開きます。終了はターミナルで Ctrl+C を押してください。クラウド内の localhost は、自分のパソコンの localhost とは別です。このクラウドのオンボーディング画面にはWebプレビュー機能がないため、手元で確認する際は上の `index.html` を開く方法を使ってください。

通常の起動には `npm install` は不要です。ポートを変える場合は `PORT` 環境変数で指定できます。

## 使用技術・ファイル

- HTML / CSS / 通常のJavaScript：画面表示と操作。フレームワークや外部フォントは使用しません。
- Node.js 標準のHTTPサーバー：開発用の配信。
- Playwright：ブラウザ操作の自動テスト（開発用の依存関係のみ）。

`index.html` が入口、`style.css` が見た目、`app.js` が画面遷移とサンプル候補、`server.js` が開発用サーバーです。キャラクターは `index.html` の `.character` 要素に置き、後から画像へ差し替えられます。将来のAI接続は `app.js` の候補データやコメント取得部分を置き換える形で拡張できます。

## テスト

```sh
npm ci
npx playwright install chromium
npm test
```

このクラウド環境では既存の `/usr/bin/chromium` を利用するため、ブラウザの追加インストールは不要です。別のブラウザ実行ファイルを利用する場合は `CHROMIUM_PATH` 環境変数にそのパスを指定できます。

テスト対象は空入力、回答、ギブアップ、追加候補の開閉、5候補の選択、選択変更、選ばず完了、仮ことば帳、再試行、入力の安全な表示、320〜1440pxの画面幅です。
