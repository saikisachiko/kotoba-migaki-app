# 言葉磨きアプリ

言葉の表現力を広げるためのWebアプリです。

## 今回のプロトタイプ

スマートフォンを中心にした、利用者向けの3画面のWebアプリです。

1. 今日の問題を読み、自分の言葉を入力します（思いつかない場合はギブアップできます）。
2. 自分の表現と固定のAIコメントを見て、5つの言い換え候補から選びます。「持ち帰る」は追加候補を開いたときだけ表示されます。
3. 「今日の一言にする」または「今日は選ばない」で完了します。

AI API、ログイン、データベース、本物のことば帳は未実装です。「ことば帳に追加しました」は仮表示で、再読み込みすると入力・選択は消えます。サーバーにも保存しません。

## いちばん簡単な確認方法（インストール不要）

このリポジトリのファイルをダウンロードして展開し、`index.html` をダブルクリックしてブラウザで開いてください。`app.js`、`phrase.js`、`candidates.js`、`style.css` は、`index.html` と同じフォルダーに置いたままにしてください。インターネットやAPIキーは不要です。

GitHubへ反映された後は、リポジトリ画面の緑色の「Code」→「Download ZIP」で取得できます。

まず好きな短い表現を入力して「この言葉にする」を押し、候補を選び、「今日の一言にする」を押してください。「もう一度試す」からギブアップや「今日は選ばない」も確認できます。

## 開発用の起動方法

Node.js 22以上を使用します。ターミナルで、このリポジトリのフォルダーに移動して次を実行します。

```sh
npm start
```

起動中のパソコンのブラウザで `http://localhost:3000` を開きます。終了はターミナルで Ctrl+C を押してください。クラウド内の localhost は、自分のパソコンの localhost とは別です。このクラウドのオンボーディング画面にはWebプレビュー機能がないため、手元で確認する際は上の `index.html` を開く方法を使ってください。

通常の起動には `npm install` は不要です。ポートを変える場合は `PORT` 環境変数で指定できます。

## 使用技術・ファイル

- HTML / CSS / 通常のJavaScript：画面表示と操作。フレームワークや外部フォントは使用しません。
- Node.js 標準のHTTPサーバー：開発用の配信。
- Playwright：ブラウザ操作の自動テスト（開発用の依存関係のみ）。

`index.html` が入口、`style.css` が見た目、`app.js` が画面遷移・お題データ、`candidates.js` がサンプル候補と選定ルール、`phrase.js` が対象箇所の置換、`server.js` が開発用サーバーです。キャラクターは `index.html` の `.character` 要素に置き、後から画像へ差し替えられます。将来のAI接続は `app.js` の候補データやコメント取得部分を置き換える形で拡張できます。

## テスト

```sh
npm ci
npx playwright install chromium
npm test
```

このクラウド環境では既存の `/usr/bin/chromium` を利用するため、ブラウザの追加インストールは不要です。別のブラウザ実行ファイルを利用する場合は `CHROMIUM_PATH` 環境変数にそのパスを指定できます。

テスト対象は空入力、回答、ギブアップ、追加候補の開閉、5候補の選択、選択変更、選ばず完了、仮ことば帳、再試行、入力の安全な表示、320〜1440pxの画面幅です。

## 自分の言葉の表示ルール

「あなたの言葉で文章にすると」と完了画面の「自分の言葉」は、元のお題の対象部分だけを入力値にそのまま置換します。文末や前後の語句を生成・補完しません。お題を変更する際は `app.js` の `problem` の `context`（状況）、`original`（元文）、`target`（置換対象）を設定してください。同じ対象が複数ある場合は最初の1箇所だけを置換し、空の対象や元文に存在しない対象は設定エラーとして扱います。

## 候補生成・選定ルール（将来のAI接続時にも必須）

- ユーザーの表現から、すでに使っている中心語・語幹を把握し、同じ語彙の活用・敬語・接頭辞・接尾辞の違いだけの候補を除外します。例：「検討させてください」に対する「検討する」「検討します」「検討させていただく」「ご検討」は提示しません。
- 通常2候補、視点を変える2候補、追加1候補の計5候補すべてで、中心語が重複しないよう選定します。カテゴリーをまたいだ重複も除外します。「活用」と「有効活用」は重複、「活用」と「応用」は異なる語彙として扱います。
- 単に異なる文字を選ぶのではなく、元のお題に自然に使えて、意味・ニュアンス・視点の違いが説明できる表現を生成します。
- プロトタイプでは手作業で吟味した代替サンプルを用意し、`coreTerms` に中心語・語幹・表記ゆれを記載しています。「検討させてください」なら通常候補は「確認する」「精査する」です。全角・半角や空白を正規化して照合します。自由な日本語全般を解析する形態素解析器ではありません。
- AI接続時は上記を生成指示に含め、中心語・語幹と表記ゆれのメタデータを持つ候補を多めに生成し、`selectCandidates` で検証してから表示してください。未知の活用・表記は語幹解析やメタデータの拡充が必要です。
- 重複除外後に必要数がそろわない場合は、除外済みの中心語を指定して再生成・再検証してください。重複を戻して枠を埋めません。現在の固定サンプルの語彙を入力がすべて含む場合などは候補数が減りますが、「今日は選ばない」で完了できます。
